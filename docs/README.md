# ZY WANG 作品集網站：更新說明

## 資料夾裡有什麼

| 檔案 | 用途 | 需要改嗎？ |
|---|---|---|
| `content.js` | **所有內容**：作品、相簿、自我介紹、聯絡方式 | ✅ 平常只改這個 |
| `images/` | 放你自己的圖片 | 需要時放圖進去 |
| `index.html` | 網頁外框 | ❌ 不用動 |
| `app.js` | 網站運作程式 | ❌ 不用動 |
| `style.css` | 顏色、字體、排版 | 想換顏色時才改最上面幾行 |

網站結構：**首頁 → 工作類型（分類頁）→ 單一作品頁**。人像攝影是：**分類頁 → 單一相簿**。

---

## 新增一部影片作品

1. 打開 `content.js`，找到 `works: [`
2. 把下面這段複製，貼在 `works: [` 的**下一行**（放最上面＝排在最前面）
3. 改成你的資料，存檔

```js
    {
      title: "作品名稱",
      year: 2026,
      type: "劇情短片",
      roles: "編導／攝影／剪輯／調光",
      categories: ["編導", "剪輯調光"],
      youtube: "https://youtu.be/xxxxxxxxxxx",
      cover: "",
      awards: [],
      note: "",
    },
```

**每一欄的意思：**

- `title`：片名
- `year`：年份。填了就會自動出現在「經歷」的年表
- `type`：片種，例如 劇情短片、紀錄片、形象廣告、音樂影像、短影音
- `roles`：你的職位，用 `／` 隔開
  - 跟別人一起做的寫成 `剪輯（與某某）`，網站會顯示「ZY WANG、某某」
- `categories`：這部片要出現在哪些分類，可以填好幾個。可用的名稱：
  `"編導"`、`"動態攝影"`、`"剪輯調光"`、`"動畫特效"`
- `youtube`：直接貼 YouTube 網址，任何格式都可以（youtu.be、watch?v=、shorts 都行）
- `cover`：封面圖。**留空 `""` 會自動用 YouTube 縮圖**
- `awards`：得獎紀錄，會自動出現在作品頁和「獎項」列表
  - 例如 `["2026 某某影展 首獎"]`，沒有就寫 `[]`
- `note`：補充，例如 `"朝陽科技大學 畢業製作"`

> **只想列在經歷年表，沒有影片？** 只寫這幾項就好：
> `{ title: "片名", year: 2026, roles: "攝影／調光" },`

## 新增一組人像相簿

在 `content.js` 找到 `albums: [`，複製一組貼上：

```js
    {
      id: "new-album",
      title: "日系外拍",
      model: "模特名字",
      cover: "images/封面.jpg",
      photos: [
        "images/照片1.jpg",
        "images/照片2.jpg",
      ],
    },
```

`id` 會用在網址裡，請用英文或數字，而且不要跟其他相簿重複。

---

## 使用自己的圖片

1. 把圖片放進 `images/` 資料夾
   - 檔名建議用英文，不要有空格，例如 `ghost-school.jpg`
2. 在 `content.js` 裡寫 `"images/ghost-school.jpg"`

> 建議先把圖片縮到長邊 2000px 以內、存成 JPG，網站會載入得比較快。

---

## 修改其他內容

這些都在 `content.js` 裡，直接改引號裡的文字就好：

- **聯絡方式**：`contact`。電話不想公開就改成 `phone: "",`
- **首頁標語、介紹**：`tagline`、`intro`
- **自我介紹**：`about`
- **首頁分類的封面圖**：`categories` 裡的 `cover`

---

## 改壞了怎麼辦

- 網頁會直接顯示「**content.js 第 N 行附近有格式錯誤**」
- 最常見的原因：
  - 少了逗號 `,`
  - 少了引號 `"`
  - 用了中文全形引號「“ ”」，要用英文半形 `"`
- 已經上傳到 GitHub 的話，每一次修改都有紀錄，可以隨時還原到之前的版本

## 在自己電腦上預覽

**雙擊 `預覽網站.command`**，瀏覽器會自動打開網站，YouTube 影片也能在頁面裡直接播放。看完把跳出來的終端機視窗關掉就好。

> 直接雙擊 `index.html` 也能看，但 YouTube 不允許這種方式在頁面內播放影片，只會顯示「到 YouTube 觀看」。網站上線後就沒有這個問題。
>
> 第一次雙擊 `預覽網站.command` 時，Mac 可能會詢問是否允許「終端機」存取「文件」資料夾，請按「允許」。

## 上線（永久免費）

使用 **GitHub Pages**：

1. 註冊 / 登入 GitHub
2. 建立一個新的 repository，名稱例如 `portfolio`
3. 把這個資料夾裡的所有檔案上傳
4. 到 **Settings → Pages**，Source 選 `main` branch，按 **Save**
5. 幾分鐘後網站就會出現在 `https://你的帳號.github.io/portfolio/`

**以後更新：** 在 GitHub 網頁上點開 `content.js` → 按鉛筆圖示編輯 → 按 **Commit changes**。一兩分鐘後網站就會更新，在任何一台電腦上都可以改。
